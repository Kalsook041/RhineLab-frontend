# 登录开屏动画与验收

画面采用原生 SVG 活文字/路径、Canvas 粒子和 WebGL 地形，未以视频或截图作为运行时界面。布局覆盖整个视口；前景保持比例，背景覆盖四边。

## 交互时间轴

参考首轮1920×1080、30fps，源时间0–18.166667秒。30fps用于原片事件定位，运动渲染跟随浏览器刷新，不固定为30次/秒。

| 源时间 | 行为 |
| --- | --- |
| 0，首次等待 | 粒子地球保持旋转，点击启动并解锁完整开场声音。 |
| 0–2秒 | 球体旋转并退远，粒径同步缩小。 |
| 2.4–4.8秒 | 双螺旋进入，电源圆弧收笔、竖笔生长、文件展开。 |
| 4.8秒，登录等待 | 可编辑账户和密码；背景继续流动，左上方块持续转动。 |
| 4.8–7.967秒 | 正确提交后继续身份核验；确认后自动进入下一段。 |
| 7.967–10秒 | 确认环转为方框，轮廓扩张回声、文字与下划线分别进入。 |
| 10–15.4秒 | 开始读取权限、白卡展开、授权信息进入，再收缩退出。 |
| 15.667–18.166667秒 | WELCOME展开归位，底部进度条随字母入场完成；年份读取当前年份。 |
| 结束后 | 地形继续运动，音乐尾声延续并渐弱。 |

几何位置、尺寸、圆角、描边、透明度以源帧之间的连续插值更新；打字、闪断和黑白切换保留原片离散事件。显式 `window.__tangent.seek(seconds)` 可定位任意源时间，原片整数帧姿态仍可用于对照。

## 验证与限制

测试覆盖登录正确/错误输入、键盘焦点、暂停/重播、隐藏页面、低运动偏好、背景停驻流动、GPU回退、源帧同步、几何中间姿态及视口覆盖。运行 `npm test` 和 `npm run build`。

刷新率随设备、屏幕和负载变化；未承诺所有场景恒定60fps。准确字体微轮廓、AE粒子种子、真实快门模糊与细小拖影仍为拟合，不宣称逐像素1:1。账户校验为本地前端演示。

## 可直接使用的审查提示词

请审查此登录前端。范围为src、运行素材、依赖和测试。验收：没有工作台、后台API调用、Three.js或档案模型；npm ci后能构建运行；首次球体旋转且点击后有声启动；4.8秒等待账户输入，正确登录续播，错误留驻；身份确认自动衔接；WELCOME后音乐渐弱、背景继续流动；原片事件时点不被高刷新率插值改写，源帧之间几何确实变化；暂停、重播、隐藏页面、低运动偏好和窄屏无回归。运行npm test、npm run build，并对照src/renderers中的参数。仅报告可复现的可行动发现，格式为“优先级、文件行号、复现步骤、预期/实际、证据、最小修复建议”；没有问题请明确说明。

## 自查与修复提示词

已修正发布范围中的工作台动态入口、API代理、多余Three依赖和模型素材；保留纯登录的源码与资源。刷新率修正移除30Hz取整/限频，并为连续几何增加亚帧插值，保留离散事件。自查还发现隐藏WELCOME切片每次刷新重复更新，已在未入场和稳定结束区间跳过。最终测试结果见README交付验证记录。

修复提示词：按上述验收复核；只对新的可复现问题作最小修复，重跑受影响测试与构建。不得加入工作台、后端依赖或运行时视频，不改已确认的源时间节奏。若没有可行动发现，保持代码不变，说明检查范围与帧率/视觉拟合限制。
